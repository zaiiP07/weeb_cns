Hojas de Estilo en Cascada

CSS3

El lenguaje de diseño que da color, tipografía, espaciado y adaptabilidad a los documentos HTML.

¿Qué es CSS?

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada). Permite separar la estructura del contenido de su presentación visual.

Existen tres formas de aplicar CSS a una página:

  • CSS Externo (Recomendado): Mediante un archivo independiente como construye.css enlazado con <link>.
  • CSS Interno: Dentro de la etiqueta <style> en el <head> del documento.
  • CSS en Línea: Directamente en el atributo style="" de una etiqueta HTML.

Tabla de propiedades CSS fundamentales

Referencia rápida de propiedades utilizadas en el diseño de interfaces web:

Propiedad Descripción Valores de ejemplo
color Cambia el color del texto de un elemento. #2c4a63, navy, rgb(44, 74, 99)
background-color Define el color de fondo de una caja o página. #f3f8f9, #e3f2ed
font-size Establece el tamaño de la tipografía. 16px, 1.15rem
margin Controla el espacio exterior alrededor del borde. 20px, 0 auto
padding Controla el espacio interior entre el contenido y el borde. 15px 25px
border-radius Redondea las esquinas de tarjetas, botones e imágenes. 12px, 50%
display Define el comportamiento de distribución del contenedor. flex, grid, block
