Lenguaje de Marcado

HTML5

El lenguaje estándar que permite estructurar y dar significado semántico al contenido de las páginas web.

¿Qué es HTML?

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto). No es un lenguaje de programación, sino un lenguaje de estructura que indica al navegador qué representa cada bloque de información mediante etiquetas.

Con la llegada de HTML5, se incorporaron etiquetas semánticas (<header>, <nav>, <article>, <section>, <footer>) y soporte nativo para audio y video sin complementos externos.

Tabla de etiquetas HTML esenciales

Consulta las etiquetas más utilizadas agrupadas por categoría y ejemplo de sintaxis:

Etiqueta Categoría Función Ejemplo de uso
<h1> ... <h6> Texto Define encabezados jerárquicos (siendo <h1> el principal). <h1>Título principal</h1>
<p> Texto Crea un párrafo de texto estándar. <p>Bienvenido a mi sitio.</p>
<a> Navegación Inserta un hipervínculo hacia otra página o sección. <a href="contruye.html">Ir a CSS</a>
<img> Multimedia Muestra una imagen (etiqueta de autocierre). <img src="htmIm.png" alt="Logo">
<ul> / <ol> Listas Crea listas desordenadas (viñetas) u ordenadas (números). <ul><li>Elemento</li></ul>
<table> Datos Organiza información en filas (<tr>) y celdas (<td>). <table><tr><td>Dato</td></tr></table>
<form> Interacción Agrupa controles de entrada como <input> y <button>. <form><input type="text"></form>

Ejemplos prácticos interactivos

Selecciona una pestaña para explorar el código y su resultado visual:

Código HTML5

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi primera web</title>
</head>
<body>
    <header><h1>Hola mundo</h1></header>
    <main><p>Contenido principal.</p></main>
    <footer><small>Pie de página</small></footer>
</body>
</html>

Explicación de partes

  • <!DOCTYPE html>: Indica al navegador que use el estándar HTML5.
  • <head>: Contiene metadatos, título de pestaña y enlaces a CSS.
  • <body>: Contiene todo lo que el usuario ve en pantalla.
  • Semántica: Etiquetas como <main> mejoran la accesibilidad y el SEO.

Código de Listas

<!-- Lista desordenada -->
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
</ul>

<!-- Lista ordenada -->
<ol>
    <li>Abrir editor</li>
    <li>Guardar como .html</li>
</ol>

Código de Tabla

<table class="table">
  <thead>
    <tr><th>Etiqueta</th><th>Significado</th></tr>
  </thead>
  <tbody>
    <tr><td>&lt;tr&gt;</td><td>Fila de tabla</td></tr>
    <tr><td>&lt;td&gt;</td><td>Celda de dato</td></tr>
  </tbody>
</table>
