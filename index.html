¿Qué es una aplicación web?

Es un programa que se ejecuta directamente desde un navegador web sin necesidad de instalación local, permitiendo interactuar con información mediante Internet o una red.

HTML: Estructura y Contenido

Es el esqueleto de toda página web. Mediante etiquetas semánticas define títulos, párrafos, listas, tablas, imágenes, botones y formularios.

  • Organiza jerárquicamente la información.
  • Conecta páginas mediante hipervínculos.
  • Captura datos del usuario con formularios.
Explorar guía HTML

CSS: Diseño y Apariencia

Es la capa visual que transforma el esqueleto HTML en una interfaz atractiva: define paletas de color, tipografías, espacios y adaptación móvil.

  • Controla colores, fondos, bordes y sombras.
  • Maqueta columnas con Flexbox y CSS Grid.
  • Adapta el diseño a celulares, tabletas y PC.

Pasos para construir una página web

Sigue este orden recomendado cuando desarrolles tu proyecto escolar:

  1. Planificar la estructura
    Define qué secciones tendrá tu sitio (inicio, temas, tablas, multimedia y contacto).
    Paso 1
  2. Maquetar el contenido en HTML
    Escribe las etiquetas semánticas (<header>, <nav>, <main>, <section>, <footer>).
    Paso 2
  3. Aplicar estilos con CSS y Bootstrap
    Enlaza tu hoja construye.css y usa clases responsivas para armonizar colores y espacios.
    Paso 3
  4. Probar interactividad y responsividad
    Verifica enlaces, reproducción de video, formularios y visualización en pantallas pequeñas.
    Paso 4

Ejemplo práctico rápido

Así trabajan juntos HTML y CSS en un mismo botón:

<!-- HTML crea el elemento -->
<button class="btn-ejemplo">Enviar</button>

/* CSS le da estilo */
.btn-ejemplo {
  background: #76b5a0;
  color: #ffffff;
  border-radius: 10px;
}

Comparación entre HTML y CSS

Analiza las diferencias clave entre ambos lenguajes y filtra por aspecto.

Tabla comparativa técnica
Aspecto HTML CSS
Función principal Organiza y estructura el contenido de la página. Define la presentación visual, colores y diseño.
Sintaxis Utiliza etiquetas de apertura y cierre (ej. <p>...</p>). Utiliza selectores y bloques de propiedades (ej. p { color: blue; }).
Elementos que maneja Títulos, textos, imágenes, enlaces, listas, tablas y formularios. Tipografías, márgenes, rellenos, bordes, fondos y animaciones.
Extensión de archivo .html o .htm .css
Dependencia Puede funcionar solo, pero se ve muy básico. Necesita un documento HTML al cual aplicar los estilos.

Separar el contenido (.html) del diseño (.css) permite reutilizar una misma hoja de estilos en varias páginas (como index.html, print.html y contruye.html), facilitando el mantenimiento y evitando repetir código.

Bootstrap proporciona un sistema de rejilla de 12 columnas, barras de navegación adaptables, tarjetas, acordeones, pestañas y ventanas modales listas para usarse en cualquier dispositivo.

La etiqueta <ul> crea listas desordenadas con viñetas (ideales para características o menús), mientras que <ol> crea listas ordenadas numeradas (ideales para pasos secuenciales o rankings).
